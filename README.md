# Virgil — Local Video Remaster Tool

A desktop application for AI-powered video upscaling 
that runs entirely on local hardware.

## What it does
Virgil takes older or lower resolution video files and 
upscales them using AI models, processing everything 
locally on your GPU. No internet required after setup, 
no data sent anywhere.

Successfully tested on Dragon Ball GT, Blackadder 
and Looney Tunes source files.

## Tech stack
- Electron
- FFmpeg
- Video2X
- Node.js
- Windows 11

## Hardware
Developed and tested on AMD Ryzen 7 5700 with 
RTX 5060 Ti 16GB VRAM.

## Background
Built by a self-taught developer in Johannesburg 
through iteration and problem solving. No formal 
computer science training — learned by building.

## Status
Functional. Currently in use for personal 
remastering projects.
